AP CVVEN : Réservation de séjour

Authentification et entree dans l'application de reservation

Organisation : CVVEN (Comité pour les Villages de Vacances de l'Éducation Nationale)

Période : année 2025/2026

Contexte : conception d'une application web de gestion et réservation de locations, avec architecture MVC (Modèle-Vue-Contrôleur) et base MySQL.

Fonctionnalités réalisées

  • Authentification utilisateur et controle d'acces par role
  • Consultation des chambres et reservation de sejours
  • Gestion des chambres et des reservations (creation, suivi, annulation)
  • Espace utilisateur avec profil et parametres

Environnement technique

  • Langages : PHP, SQL, HTML, CSS, JavaScript
  • Framework : CodeIgniter 4
  • Base de donnees : MySQL (administration via phpMyAdmin)
  • UI : Bootstrap 5, Font Awesome
  • IDE : NetBeans
  • Tests sécurité : Burp Suite
